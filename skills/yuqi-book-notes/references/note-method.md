## Output objective

Create a working knowledge asset for the user's future self. A successful note makes it easy to recover the book's structure, understand the highest-value ideas, act on them, and reuse them in projects or content.

Use the book's own principle when it is useful for the note-making system. Preserve methods that improve future capture, organization, distillation, or expression.

## Book-style decision

Choose one dominant style and optionally one secondary style.

| Style | Signal | Emphasis |
|---|---|---|
| Framework | Named models, distinctions, causal systems | Architecture and relationships |
| Practical | Steps, formulas, checklists, exercises | Exact actions and examples |
| Case-heavy | Stories dominate explanation | Transferable decision patterns |
| Reflective | Interpretation, identity, meaning | Insight, prompts, boundaries |
| Reference | Many independent facts or tools | Retrieval structure and selection |

Do not force every book into the same density. A short, repetitive book may yield fewer themes and insights.

## Synthesis procedure

1. Create a chapter coverage ledger with one line per source unit.
2. Extract candidate ideas using the four capture criteria.
3. Merge duplicates across chapters.
4. Group candidates by the problems they solve, decisions they improve, or mechanisms they explain.
5. Name 3–7 Level 1 themes with short, parallel phrases.
6. Select 2–4 Level 2 insights under each theme. Fewer is acceptable.
7. Add Level 3 support only where it improves understanding or trust.
8. Add Level 4 actions only where execution benefits from details.
9. Write the three-sentence summary after the full structure is stable.
10. Derive the separate action list from the highest-leverage ideas.

## Layer rules

### Level 1 — Knowledge map

- Use 3–7 items.
- Prefer 4–10 Chinese characters or one compact sentence.
- Make items parallel in grammatical form when possible.
- Represent the reconstructed logic of the book, not chapter names.
- Avoid `概念：解释`, vague nouns such as “方法体系”, and promotional phrasing.

### Level 2 — Bold insight

- Express one falsifiable or decision-relevant claim.
- Make the entire toggle title bold.
- Avoid titles that only name a topic.
- Do not repeat the Level 1 wording.

### Level 3 — Supporting information

- Explain why the insight is true, how it works, and where it stops applying.
- Use normal text with selective bolding for the highest-value sentence.
- Preserve numbers, formulas, named steps, and necessary context accurately.
- Prefer one representative example over several similar stories.

### Level 4 — Action example

Use only when it makes action substantially easier. Suitable content includes:

- A checklist or sequence.
- A formula with a worked example.
- A decision script or diagnostic questions.
- A small experiment with duration and success signal.
- A template the user can copy.

Label the toggle `行动示例｜<short action>`.

## Application rules

Actions must start with a verb and be observable. Prefer actions that can begin today, have a clear trigger, or create a reusable asset.

Strong: `发薪日自动转出 10%，连续执行三个月后再调整比例。`

Weak: `培养储蓄意识。`

For the user's likely projects, consider connections to personal knowledge management, AI-tool development, content creation, personal IP, decision systems, and reusable templates. Include only connections supported by the book.

## Quality failures

- Empty abstraction: concepts appear without mechanisms, examples, or action.
- Encyclopedia mode: completeness is prioritized over future usefulness.
- Directory mirroring: the original chapter order becomes the note structure.
- Example dumping: stories survive even when their lesson is already clear.
- Forced links: a related book is named without explaining a useful relationship.
- Action theater: actions are motivational but cannot be observed or started.
- Unsupported personalization: personal recommendations are invented without user context.
- False currency: dated claims are presented as current facts.
